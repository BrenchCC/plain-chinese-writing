# 中文文档写作

`plain-chinese-writing` 是一个用于起草和修改中文文档的 Codex Skill。它帮助作者把结论、依据和例子按清楚的逻辑写出来，减少空泛免责声明、重复套话和装饰性标点。完整规则见 [SKILL.md](SKILL.md)。

## 一、适用范围

适用于中文说明文、报告和技术文档的资料整理、起草与润色。Skill 会保留用户指定的体裁、结构和引用要求；资料不足时指出具体缺口，不编造事实。

## 二、写作规则

- 先交代核心结论或讨论范围，再展开解释与证据。每段第一句概括该段的对象、判断或结论。
- 让句子之间的并列、递进、因果或比较关系清楚。主语、动作和指代应明确。
- 需要分级标题时，一级使用“一、”“二、”，二级使用“1.1”“1.2”；一级章节最多五个，标题简短且不加标点。
- 删除不提供信息的客套话、重复总结和模糊风险提示。重要限制应写明适用条件及具体影响。
- 避免无意义的引号、破折号、箭头，以及“不是……而是……”“不意味着……”等绕行句式。
- 举例只选能说明观点的代表项。同一句用顿号连接的例子不超过三项；更多内容改用列表。表格上方先写内容的总结描述。

## 三、按需输出

技术内容需要从代码理解时，先用文字说明目标和关键步骤，再给出对应代码，并注释关键语句的作用或原因。

仅在要求输出 Word 文档时，使用黑色文字、宋体五号正文和 1.2 倍行距；文档标题为黑体二号，一级标题为宋体三号加粗，二级标题为宋体四号加粗。表格采用三线表，表头加粗，表内正文五号，图表注释六号。

## 四、安装和使用

将仓库克隆到 Codex 的 Skill 目录：

```bash
git clone https://github.com/BrenchCC/plain-chinese-writing.git ~/.codex/skills/plain-chinese-writing
```

在写作请求中指定 `$plain-chinese-writing` 即可。例如：

```text
使用 $plain-chinese-writing 润色这份技术报告，保留事实和引用，理顺段落逻辑。
```
